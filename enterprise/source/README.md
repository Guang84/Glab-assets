# Source Files

Editable master files, not the primary location for ready-to-use exports.

- `vector/` — SVG and vector source.
- `raster/` — layered raster artwork and high-resolution source images.
- `design-files/` — native design-project files.
- `editable-documents/` — editable document and presentation masters.

Link each source to its approved export in the asset register. Avoid temporary caches and generated backups.
