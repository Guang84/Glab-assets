# Brand

Shared GLab ecosystem identity standards and reusable brand assets.

## Sections

- `logos/` — approved shared GLab logos in primary, alternate, and monochrome variants.
- `guidelines/` — identity and usage guidance.
- `colors/` — core GLab and product-specific palettes.
- `typography/` — font guidance and specimens.

Use these shared resources only where the GLab brand system applies. GLab Enterprise-specific corporate treatments belong in `/enterprise/identity/`. Preserve original logo artwork and third-party font licenses.
