# Product Assets

Store assets specific to individual GLab applications, websites, and projects here.

## Collections

- `apps/` — copy `apps/_template/` and rename it to the application slug.
- `websites/` — copy `websites/_template/` and rename it to the website slug.
- `projects/` — copy `projects/_template/` and rename it to the project slug.

The GLab Enterprise corporate library is maintained separately at the repository root in [`/enterprise/`](../enterprise/README.md). A generic starter for a distinct future enterprise offering is available under `resources/templates/enterprise-offering/`.

Shared ecosystem-wide resources belong in `/brand/` or `/shared/`. Preserve source files, credits, asset numbering, and rights notices.
