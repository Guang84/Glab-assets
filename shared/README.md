# Shared Assets

Reusable visual assets that can be used across authorized GLab applications, websites, projects, and documentation.

- `icons/` — shared app, website, product, and interface icons.
- `illustrations/` — general, product, and interface illustrations.
- `wallpapers/` — desktop and mobile wallpapers.

Product-specific or Enterprise-only artwork belongs in its corresponding collection, not here. Keep creator credits and license details with third-party materials.
