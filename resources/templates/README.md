# Reusable Templates

Shared templates for GLab projects and future offerings.

- `documents/` — reusable document masters.
- `presentations/` — reusable presentation masters.
- `design-files/` — reusable design source files.
- `enterprise-offering/` — starter structure for a separate future enterprise product/service/module. The current GLab Enterprise corporate library lives at `/enterprise/`.

Include required fonts, attribution, source, and license information with every template.
