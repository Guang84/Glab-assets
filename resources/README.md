# Resources

Reusable materials intended to support multiple GLab projects.

- `banners/` — shared web, GitHub, and event banners.
- `social-media/` — reusable avatars, covers, posts, and stories.
- `templates/` — reusable document, presentation, design-file, and enterprise-offering starters.

Keep assets that are unique to a specific app, website, project, or GLab Enterprise in their dedicated collections.
